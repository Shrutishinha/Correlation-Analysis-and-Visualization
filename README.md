# 🧠 About the Project

> 🌈 **From raw numbers to meaningful patterns.**

This project performs **Exploratory Data Analysis (EDA)** and **Correlation Analysis** on the **California Housing Dataset** to uncover relationships, dependencies, and hidden patterns among numerical features.

### 🎯 The Mission

```text
📥 RAW DATA
     ↓
🔎 EXPLORE
     ↓
🧹 UNDERSTAND
     ↓
📊 CALCULATE CORRELATION
     ↓
🔥 VISUALIZE RELATIONSHIPS
     ↓
🧠 INTERPRET PATTERNS
     ↓
💡 EXTRACT INSIGHTS
```

> **Goal:** Transform complex numerical relationships into clear, visual, and actionable insights.
